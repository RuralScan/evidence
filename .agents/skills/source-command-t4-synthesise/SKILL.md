# T4 scientific synthesis

Use `workflows/t4_synthesis/README.md` and its pinned contract. This route authors
proposals, not human approvals. CIAT is a read-only source of pinned history and
structural readers. Never run the retired scientific compiler or write CIAT registers.

1. Confirm the authorised practice, current family, quantity and context. Prepare
   frozen inputs. Discovery and extraction require their own authorisation.
2. Inspect all candidate passages, source profiles, reviewer reasons and prior
   mappings. Give every candidate a disposition, reason and originating study.
   Broader evidence stays visible; it cannot silently inherit a child's scope.
   Sibling and unresolved historical family attribution requires source review.
3. Assess variable use, suitability direction and numerical calibration separately.
   Keep observed settings and model importance as context. Neither supplies a
   suitability endpoint, interpolation rule, exclusion or criterion weight.
   Retain complete regional profiles; regional origin alone does not invalidate them.
4. Explain compatibility, origin dependence, measurement/statistic, spatial support,
   units, precision and mechanism. A common unit does not establish compatibility.
   Preserve contradictory results. More sources do not resolve an unsupported proxy.
5. Author the simplest supported representation. Check each endpoint and both sides,
   missing values, unknown classes and declared tails. Record the expected outputs
   and why the examples are scientifically appropriate. Validation only checks that
   those examples match the authored function; a reviewer judges plausibility.
6. Keep calibration, transfer and applicability holds explicit. Source Keep does not
   approve a numerical curve. Species envelopes do not set practice suitability;
   crop admission follows the pinned policy. Soft operational evidence stays M2b.
7. Explain dataset binding and contextual transfer. Separate masks from compensatory
   scores and source importance from runtime criterion weights. Missing weights stay
   blank. This mapping package does not invent a complete T4_RUN execution policy.
8. Compare with prior rows. Explicitly fingerprint each replacement or withdrawal.
   Preserve evidence IDs and review history. Supersession requires a new proposal;
   a changed input packet or held decision cannot be revived by editing its snapshot.
9. Record actual model, complete prompt, skill version and exposed settings (say
   unavailable when not exposed). Validate and stage exact bytes for human review.
   Do not create an acceptance issue on a reviewer's behalf.
10. After an eligible human's original acceptance receipt, record through the
    protected PR route. Packaging reproduces exact accepted values, not another AI
    answer. Held or stale rows block packaging. Runtime integration is separate.

Scientific review must challenge omissions as well as invented values: source-table
coverage, native class meanings, false precision, abrupt exclusions, missing tails,
proxy duplication, dependence and local-to-global transfer. Unsupported forms remain
qualitative/calibration-held until the contract and scientific proposal are reviewed.


## Exact profiles and pending overrides

Inspect `inputs.json.override_candidates` when preparing a rule. These records come
from the authoritative `suitability/overrides/overrides.csv`; typed candidate JSON
is generated. Explain the disposition of applicable pending overrides in proposal
reasoning and before/after comparison. A pending record is a review proposal, not
permission to change accepted mappings or suppress existing criteria.

Contract 1.1 supports exact logistic/log-logistic profiles, typed nested minima,
explicit subpractice/pathway scope, named component screens, temperature-only
season derivation and precomputed unit scores with separate source-area accounting.
Use the declared parameters; never approximate smooth curves or silently substitute
coupled climate variables. Source-linked policy choices must stay distinguishable
from empirical source claims. Every raw/derived quantity still needs adopted
VONT/T1/preferred BIND definitions for official publication; metadata citations are
not Evidence Register units. A rule can cover multiple practices in the catalogue,
but official proposals remain one current family each.

Keep scores, exclusions, unknowns and conditional water pathways separate. Retain
independent host/legal gates. A precomputed support polygon is not an opportunity
footprint; never use score-weighted hectares or polygon fractions as source-area
allocation. No new weight is inferred. Validate the exact boundary and state
examples, then follow the unchanged scientific-acceptance route. Source admission,
software merge and a passing preview are not scientific approval or runtime activation.
